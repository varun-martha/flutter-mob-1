# Task 4 — Add Bottom Tab Navigation

Enhance the app by adding **bottom tab navigation**.

- Add a **BottomNavigationBar** to the app  
- Create at least 2 tabs:
  - **Home**
  - **Profile**

- The Profile tab should show the existing Profile screen  
- The Home tab can display a simple placeholder UI (e.g., "Home Screen")  

- Switching tabs should update the screen accordingly  
- Keep the UI simple and beginner-friendly  

- The **currently active tab should be highlighted**
  - Add an **underline indicator** below the selected tab
